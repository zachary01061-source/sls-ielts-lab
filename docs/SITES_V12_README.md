# SLS IELTS Lab

阅读、听力、口语、写作与语料库练习平台。公开入口无需注册或登录；作答记录、收藏和草稿保存在当前浏览器。

本次交付以项目根目录中的源码为正式版本。原上传项目中需要保留的后端、Vue源文件和不同版本资料收在 `legacy_source/`，不作为默认构建入口。

线上通过独立补录索引合并这篇文章，原969个题库JSON保持原字节。Q29的来源答案为D；本库依据题干所问的作者立场采用C，并在 `sourceAnswerKeys` 与 `answerReviewNotes` 中保留来源答案及差异解析，避免把转述的经济学家意见直接等同于作者观点。

“当季必考”是本季重点复习标签，各场次实际题目会有不同；简单／中／难用于教学分层，并非官方难度评级。冲刺考情窗口为2026年10月19日至11月18日，依据公开考生反馈日期整理，未覆盖全部场次。

## 安装、开发与构建

使用Node.js ≥22.13.0及pnpm 11.25.0，在项目根目录运行：

```bash
pnpm install --frozen-lockfile
pnpm run dev
```

使用终端打印的网址访问公开前端。不要双击HTML文件运行。

构建及预览构建结果：

```bash
pnpm run build
pnpm run start
```

默认构建使用当前根目录源码，不运行 `legacy_source/frontend/` 的旧Vue构建。保留 `pnpm-lock.yaml`，不要混用旧项目的npm锁文件。

## 音频和部署

线上站点与导出包的音频地址分别维护：线上继续使用现有媒体服务；完整ZIP使用本地录音和图片路径。原581条录音采用上传包中的OGG文件，并同步保留其时长、格式、大小和SHA-256；新剑桥资源按核实后的映射加入，不修改线上原题库文件。

生产数据库、生产环境密钥、账号会话和学生私人记录不随源码导出。原上传包中的运行数据库、真实`.env`与依赖缓存已排除，仍应留在原运行环境。教材／语料服务等使用现有部署绑定，正式发布时保留站点身份、DB／BUCKET及既有环境配置。框架和服务部署资料见 `docs/HOSTING_STARTER.md`。

源资料和教学题库用于本项目学习与教学。继续公开发布或转交时，应保留题库来源信息和现有使用范围。
